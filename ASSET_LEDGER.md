# Asset ledger

Every shipped asset has a row: id (path), creator, licence, date, source.
`npm run check-content` fails if a file under `app/src/main/assets` or
`app/src/main/res` is not covered. A path ending in `/` covers that folder.

Art, icons and sounds are original to this project and generated by code at
runtime (SVG illustration and synthesised tones); there are no image or audio
files. The only third-party assets are two fonts under the SIL Open Font
License 1.1, which permits bundling in commercial software; their licence
texts ship beside them. Nothing comes from any reference game.
