# Asset ledger

Every shipped asset has a row: id (path), creator, licence, date, source.
`npm run check-content` fails if a file under `app/src/main/assets` or
`app/src/main/res` is not covered. A path ending in `/` covers that folder.

All MVP assets are original to this project. Creature art, icons and sounds are
generated by code at runtime (SVG shapes and synthesised tones); there are no
image, font or audio files and nothing from any third party or reference game.
